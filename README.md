# מחולל קיצורי דרך לאנדרואיד

האפליקציה מוסיפה לאנדרואיד סוג קיצור דרך בסגנון ווינדוס: קובץ בסיומת `.link` שמכיל כתובת של קובץ, אפליקציה או תיקייה.

## שימוש
1. פתח את האפליקציה ממסך הבית.
2. בחר "קיצור לקובץ או לאפליקציה" או "קיצור לתיקייה", ובחר את היעד.
3. בחר היכן לשמור את קובץ ה-`.link`.
4. בסייר הקבצים, לחיצה על הקובץ תפתח את היעד מיד.

## בנייה
כל push ל-GitHub בונה אוטומטית APK דרך GitHub Actions. ה-APK מופיע בלשונית Actions ← Build APK ← Artifacts, בשם `app-debug`.

## לפני פרסום
- שנה את `namespace` ו-`applicationId` ב-`app/build.gradle.kts` לשם חבילה משלך.
- ה-APK הנבנה הוא Debug. להפצה רחבה יש לחתום על Release.

## מגבלות ידועות
- זיהוי הסיומת `.link` תלוי בסייר הקבצים. חלק מהסיירים שולחים את הקובץ כ-`application/octet-stream`, ולכן האפליקציה רשומה גם לסוג הזה. כתוצאה מכך היא עשויה להופיע כאפשרות ל-"פתח עם" גם לקבצים בינאריים אחרים, והיא תצא בשקט אם הקובץ אינו `.link`.
- גישה לנתיבי מערכת מוגבלת לפי הרשאות Storage Access Framework של אנדרואיד, ולכן היעד נבחר בעזרת הבוחר של המערכת.
